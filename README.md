# My First Text-Based RPG / Моя первая текстовая игра 🎮

A simple console game written in Python to practice basic programming concepts. / Простая консольная игра на Python для практики базовых концепций программирования.

## Features / Особенности
- **Inventory System**: Dictionary-based inventory. / **Инвентарь**: Словарь для хранения предметов (зелья, золото).
- **Economy**: Buy potions with gold. / **Экономика**: Покупка зелий за золото.
- **Interactive Menu**: `while` loop for player actions. / **Меню**: Бесконечный цикл для выбора действий.

## How to run / Как запустить
```bash
python Game.py
